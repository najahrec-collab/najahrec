# دليل تشغيل موقع مكتب النجاح للاستقدام (Al Najah Recruitment Office)

موقع تعريفي وتفاعلي متكامل لمكتب النجاح للاستقدام، مبني بأحدث تقنيات الويب الأساسية (HTML5, Vanilla CSS3, JavaScript) بشكل متجاوب بالكامل وتصميم فاخر (Premium Navy & Gold) مع لوحة تحكم إدارية ونظام إدارة وتصفية السير الذاتية وحاسبة تكاليف تفاعلية.

تم تصميم الموقع بهيكل **الصفحات المتعددة (Multi-Page Architecture)** لتسهيل تصفح الأقسام ومحركات البحث.

## 🔐 بيانات دخول لوحة التحكم (Admin Dashboard)

* **رابط اللوحة:** افتح ملف `admin.html` في المتصفح، أو انقر على رابط "لوحة التحكم 🔒" في أسفل تذييل الموقع.
* **كلمات المرور المعتمدة:**
  - `admin123`
  - `najah2026`
  - `123456`

### مميزات لوحة التحكم:
1. **إحصائيات فورية:** إجمالي السير الذاتية، السير المتاحة، المحجوزة، ونسبة الإشغال.
2. **إدارة السير الذاتية:** إضافة سيرة جديدة، تعديل البيانات، التبديل السريع بين (متاحة / محجوزة)، أو حذفها.
3. **إدارة تكاليف ومدد حاسبة الاستقدام:** تعديل الأسعار، مدة الوصول، والرواتب لكل جنسية ومهنة مع انعكاس لحظي في الحاسبة بالصفحة الرئيسية.
4. **النسخ الاحتياطي:** تصدير كافة البيانات كملف JSON واستيرادها في أي وقت بنقرة واحدة.

## 🚀 كيفية التشغيل والمعاينة المحلية (How to Preview Locally)

### الطريقة 1: الفتح المباشر
يمكنك فتح ملف `index.html` أو أي ملف صفحة مباشرة في المتصفح (Chrome, Edge, Firefox, Safari).

### الطريقة 2: تشغيل سيرفر محلي (موصى به)
باستخدام بايثون:
```bash
python -m http.server 8000
```
ثم فتح المتصفح على: `http://localhost:8000`

## 🛠️ تفاصيل الأنظمة البرمجية

1. **نظام التصفية اللحظي بالسير الذاتية (resumes.js):**
   - يدعم البحث بالاسم والمهارات واللغات والديانة.
   - تصفية بالجنسية (10 جنسيات معتمدة).
   - تصفية بنوع المهنة ومستوى الخبرة.
   - الفرز التلقائي حسب العمر أو الأكثر خبرة.
   - فتح نافذة التفاصيل الكاملة وزر الحجز الفوري عبر واتساب برسالة مجهزة تلقائياً.

2. **حاسبة الاستقدام التفاعلية (script.js):**
   - حساب فوري للتكلفة الأساسية + ضريبة القيمة المضافة 15% + الراتب ومدة الوصول.
   - فلترة تلقائية للمهن المتاحة حسب الجنسية المختارة.
   - زر تحويل فوري للواتساب مع نص التفاصيل المحسوبة.

3. **متتبع حالة الطلب والمعاملة:**
   - فحص مراحل المعاملة الـ 7 عبر إدخال أرقام تجريبية مثل: `2026-1584` أو `2026-2001` أو `2026-1102`.
